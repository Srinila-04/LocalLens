# LocalLens — Hidden Tamil Nadu Travel & Discovery Landing Page

**LocalLens** is a modern, responsive travel and discovery landing page focused on discovering hidden places, peaceful destinations, local experiences, and lesser-known attractions across Tamil Nadu, India.

Built with **pure HTML5, CSS3, and Vanilla JavaScript** — strictly no frameworks or libraries.

---

## 🌿 Design Highlights

- **Nature-Inspired Palette**:
  - Deep Forest Green (`#163A2D`)
  - Warm Sand (`#F3E9D2`)
  - Cream Background (`#FAF8F2`)
  - Terracotta Accents (`#C96F4A`)
  - Muted Sage (`#8FA58F`)
- **Typography**:
  - Headings: *Playfair Display* (classic editorial serif)
  - Body: *Poppins* (modern clean sans-serif)
- **Interactive Features**:
  - Sticky glassmorphism header with scroll transitions
  - Smooth mobile hamburger drawer menu
  - Dynamic category filtering (🌿 Nature, ⛰️ Hills, 💧 Waterfalls, 🌊 Coast, 🥾 Adventure, 🛕 Culture)
  - Card hover lifts, image zoom transitions, and directional arrows
  - Viewport scroll reveal animations with `IntersectionObserver`
  - Active section navigation highlighting

## 🚀 How to Run

1. Open `index.html` directly in any modern web browser (Chrome, Firefox, Safari, Edge).
2. Alternatively, run with a simple local server:
   ```bash
   # Using Python 3
   python -m http.server 8000
   ```
   Then open `http://localhost:8000` in your browser.
